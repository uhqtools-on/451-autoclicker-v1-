- TUTO FRANCAIS

Si vous ne possédez pas python, veuillez installer la version 3.15 / 3.13 à ce lien : 
 https://www.python.org/downloads/windows/

Lancez le fichier "start.bat" pour installer les modules requis

Ensuite, veuillez placer le fichier "main.py" sur votre bureau. Faites ensuite :
 windows + r / cmd / écrivez "cd desktop" / écrivez "python main.py"

Vous aurez une fenêtre qui va s'ouvrir. Vous y trouverez le reste des instructions dessus.


- ENGLISH TUTO

If you do not have Python installed, please download and install version 3.15 / 3.13 from this link:
 https://www.python.org/downloads/windows/

Run the "start.bat" file to install the required modules

Next, place the "main.py" file on your desktop. Then, follow these steps:
 Press the Windows key + R, type "cmd", enter "cd desktop", and then type "python main.py".

A window will open, containing the remaining instructions.
